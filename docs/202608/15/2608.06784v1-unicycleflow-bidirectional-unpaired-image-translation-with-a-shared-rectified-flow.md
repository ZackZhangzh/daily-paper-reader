## 摘要
双向无配对图像翻译必须在无配对监督的情况下，保留源域特有结构，同时学习两个方向上的连贯变换。现有方法通常采用两个方向特定的生成器，或分别训练单向模型。即使通过循环一致性加以连接，这类模型也仅约束往返端点的重构，而不要求两个方向遵循共同的局部变换规则。我们提出UniCycleFlow，一个修正流框架，将双向翻译表示为单个时间条件速度场的前向与反向积分。该公式将两个方向组织在相同的连续动力学之内，而非将原本分离的端点映射耦合起来。一个关键挑战在于，无配对数据无法提供有意义的源-目标配对来构建修正流轨迹。UniCycleFlow通过学习确定性的源条件端点来应对这一挑战，这些端点的边缘分布通过对抗方式与目标域匹配。所得路径通过停止梯度的自流匹配进行中间速度正则化、通过离散循环闭合实现前向-反向一致性，并通过表示路径-速度正则化来控制轨迹上局部特征变化。在十个翻译方向上，UniCycleFlow使用单次Euler评估在10个任务中的7个上取得最低FID，并获得了55.1的最佳平均FID。

## Abstract
Bidirectional unpaired image translation must preserve source-specific structure while learning coherent transformations in both directions without paired supervision. Existing methods typically employ two direction-specific generators or train separate one-way models. Even when linked by cycle consistency, such models constrain only the round-trip endpoint reconstruction, without requiring the two directions to obey a common local transformation rule. We propose UniCycleFlow, a rectified-flow framework that represents bidirectional translation as forward and reverse integration of a single time-conditioned velocity field. This formulation organizes both directions within the same continuous dynamics, rather than coupling otherwise separate endpoint mappings. A key challenge is that unpaired data provide no meaningful source--target coupling from which rectified-flow trajectories can be constructed. UniCycleFlow addresses this challenge by learning deterministic source-conditioned endpoints whose marginal distributions are adversarially matched to the opposite domains. The resulting paths are regularized by stop-gradient self-flow matching for intermediate velocity supervision, discrete cycle closure for forward--reverse consistency, and representation path-velocity regularization for controlling localized feature changes along the trajectory. Across ten translation directions, UniCycleFlow achieves the lowest FID on 7 of 10 tasks using a single Euler evaluation and obtains the best average FID of 55.1.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：双向无配对图像翻译（Bidirectional Unpaired Image-to-Image Translation）要求在无源-目标配对样本的情况下，将图像在两个域之间相互转换，同时保留源域特有的结构信息，并学习两个方向的一致变换。现有方法（如CycleGAN、DCLGAN等）通常使用两个方向独立的生成器，或分别训练单向模型；即便通过循环一致性（cycle consistency）连接，也仅约束往返端点的重构误差，**并不要求正向与反向变换遵循共同的局部变换规则**，导致两个方向的变换过程缺乏内在耦合。
- **研究动机**：作者认为，理想的双向翻译应共享一个连续的动力学过程——正向和反向只是同一轨迹的不同时间方向。受整流流（Rectified Flow）和流匹配（Flow Matching）启发，论文提出用**单一时间条件速度场**统一描述两个方向的变换，从而将双向翻译建模为常微分方程（ODE）的正向和反向积分。
- **整体含义**：该工作首次将整流流框架系统性地应用于双向无配对翻译，通过共享速度场、学习源条件端点以及多层次轨迹正则化，在保持结构一致性的同时大幅提升生成质量和方向间的一致性。

## 2. 方法论（核心思想、关键技术、算法流程）

- **核心思想**：
  - 将域 A 映射到时间 `t=0`，域 B 映射到时间 `t=1`，学习一个时间条件速度场 `vθ(x, t)`，满足 ODE：`dxt/dt = vθ(xt, t)`。
  - **正向翻译（A→B）**：从 `t=0` 积分到 `t=1`；**反向翻译（B→A）**：从 `t=1` 积分到 `t=0`（即负时间步长）。两个方向共享同一个速度场，无需独立生成器或方向编码。

- **关键技术细节**：
  1. **源条件端点的学习**（解决无配对数据无法构建有效轨迹的问题）：
     - 不采用独立采样 `(xA, xB)` 作为端点对（因为随机配对混合了域差异与无关内容差异）。
     - 而是学习确定性端点映射：  
       `ˆxB = xA + vθ(xA, 0)`，`ˆxA = xB − vθ(xB, 1)`。
     - 通过对抗训练（每个域一个 PatchGAN 判别器）使生成端点 `ˆxB` 和 `ˆxA` 的边缘分布分别匹配目标域 `B` 和 `A` 的真实分布。
  2. **停止梯度自流匹配（Stop-gradient Self-Flow Matching, selfFM）**：
     - 从边界速度 `vθ(xA,0)` 和 `vθ(xB,1)` 构造中间状态 `x_t^A = xA + t·sg[vθ(xA,0)]`，`x_t^B = xB − (1−t)·sg[vθ(xB,1)]`（`sg` 表示停止梯度）。
     - 强制模型在这些中间状态上的预测速度等于 detach 后的边界速度，从而对中间轨迹提供直接监督，且不干扰端点学习。
  3. **离散循环闭合（Discrete Cycle Closure）**：
     - 约束往返重构：`˜xA = ˆxB − vθ(ˆxB, 1)` 接近 `xA`，`˜xB = ˆxA + vθ(ˆxA, 0)` 接近 `xB`，采用 L1 损失。
     - 与自流匹配互补：前者监督中间速度，后者约束端点组合的逆关系。
  4. **表示路径-速度正则化（Representation Path-Velocity, RPV）**：
     - 使用冻结的密集编码器（如 VGG16 relu5_3）提取轨迹上相邻状态 `zτ` 和 `zτ+Δ` 的特征图。
     - 对每个空间位置，计算归一化特征向量的变化率，并沿空间和两个方向取平均，从而约束局部感知特征的变化幅度，防止图像空间直线轨迹下出现感知层面的剧烈变动。

- **算法流程（训练）**：
  - 每个 batch 采样源图像，计算边界速度得到生成端点，通过判别器进行对抗匹配。
  - 同时采样随机时间 `t`，计算 selfFM 损失、cycle 损失（通过端点再翻译）和 RPV 损失（沿端点间的线性插值轨迹）。
  - 总生成器损失：`LG = λadvLadv + λselfFMLselfFM + λcycLcyc + λRPVLRPV`（权重分别为 1, 1, 1, 0.05）。
- **推理**：直接使用欧拉方法，以 K 步（主要结果 K=1）沿正向或反向积分，无需判别器或正则化分支。

## 6. 主要结论与发现

- **性能领先**：在 10 个翻译方向上，UniCycleFlow 使用 **单步欧拉推理（NFE=1）** 即在 7 个任务上取得最低 FID，并取得 **最佳十方向平均 FID（55.1）和 KID×100（2.107）**，显著优于最强基线 DCLGAN（平均 FID 62.6，KID 2.415）。
- **多步推理增益有限**：将推理步数从 1 增至 5，平均 FID 仅从 55.1 微降至 54.2，说明单步端点预测已非常强，中间状态正则化有效但并不依赖多步采样来获得高质量输出。
- **组件贡献明确**：源条件对抗端点是最大性能提升来源（FID 从 113.5 降至 69.9）；selfFM 和 Cycle 各自贡献约 8 个点提升，组合后达到 55.9；RPV 进一步将平均 FID 降至 54.2，且不增加推理成本。
- **速度场共享优于分离**：共享时间条件场显著优于独立双场（FID 54.2 vs 76.2），也优于仅共享参数但用方向 token 的方式（62.2），证明**连续时间组织**对双向一致性至关重要。
- **冻结编码器选择**：VGG16 relu5_3 在平均性能上最佳，但 DINO/DINOv2 特征也很有竞争力，表明空间对应性和语义不变性均重要。

## 7. 优点（方法或实验设计上的亮点）

- **统一动力学建模**：首次将双向翻译统一为单个 ODE 的正反向积分，从底层机制上强制正向和反向变换共享相同的局部演化规则，而非仅靠端点损失耦合。
- **巧妙应对无配对挑战**：通过对抗学习生成“伪配对”端点，而非依赖随机配对，有效避免无关内容差异对速度目标造成的干扰。
- **三层正则化互补**：
  - selfFM 直接监督中间速度；
  - cycle 约束端点组合一致性；
  - RPV 在感知特征空间约束轨迹局部平滑性；
  三者从像素、组合、感知三个层次共同约束，设计逻辑清晰且有效。
- **高效推理**：单步即可达到接近最优的性能，大幅降低部署成本，且支持在相同模型上灵活调整步数（无需重新训练）。
- **实验规范透明**：提供完整的十方向逐项消融结果，补充材料丰富；对比基线采用统一重实现，确保公平性。

## 8. 不足与局限（实验覆盖、偏差风险、应用限制）

- **不支持一对多映射**：模型输出是确定性的（给定源图像，速度场唯一），无法生成多样化的目标域风格或多种合理翻译结果，在真实场景（如风格多样性）中可能受限。
- **自流匹配依赖早期端点质量**：selfFM 使用 detach 的边界速度作为伪目标，若训练早期端点预测较差，可能将错误信号传播到中间状态，文中也承认这一点，但未提出应对策略（如置信度加权或教师模型）。
- **RPV 对编码器敏感**：虽然 VGG16 表现最佳，但不同编码器（DINO）结果仍有一定差距，且 RPV 仅约束特征变化**幅度**而非**语义方向**，可能限制对轨迹更精细的引导。
- **计算资源描述不够完整**：未报告训练总时长，也未进行多次随机种子实验，缺乏对结果稳定性的统计分析。
- **部分对比方法仅作参考**：SDEdit、EGSDE、DDIB、IBCD 等扩散/桥方法的结果来自原始论文，采用不同协议，未完全重现在统一环境下，因此不能与这些方法进行严格公平对比（尽管作者已明确标注）。
- **应用局限**：方法主要针对自然图像域对（季节、物种、地图等），未在医学影像、遥感等特殊模态上验证，泛化性有待考察；且 RPV 需要冻结的预训练编码器，对特征空间分布差异大的域可能不稳健。
