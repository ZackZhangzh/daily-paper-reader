## 摘要
我们反转了草图生成的典型范式：不按顺序绘制笔画，而是预测一个二维场，该场定义了笔画的绘制顺序。我们使用预训练的潜在流匹配变换器提供图像先验以预测中间表示，同时训练VAE的解码器以预测顺序场、笔画掩码和笔画分割。我们将预测的分割矢量化为折线，并按场对其进行排序，从而生成有序的矢量草图。我们的模型能够根据文本描述预测有序矢量草图，或将图像反渲染为有序矢量；无论哪种方式，它都遵循指定绘制顺序的文本指令。

## Abstract
We invert the typical formulation of sketch generation: instead of drawing strokes in order, we predict a 2D field that defines the order in which strokes are drawn. We use a pretrained latent flow-matching transformer to supply the image prior to predict an intermediate representation, while training the VAE's decoder to predict the order field, stroke mask, and stroke segmentation. We vectorize the predicted segmentation into polylines and sort them by the field, producing an ordered vector sketch. Our model can predict an ordered vector sketch from a text description or derender an image into ordered vectors; for either, it follows text instructions specifying the order of drawing.

## 1. 核心问题与研究动机

**核心问题**：传统草图生成方法按照固定顺序逐笔绘制，绘制顺序要么由模型自回归决定，要么不被显式表达。本文提出逆向思维：**不直接生成笔画序列，而是先预测一个定义绘制顺序的二维场（order field），再据此排序笔画**。

**研究动机**：
- 现有方法（自回归、扩散、逐图优化、多模态LLM等）均**不将绘制顺序作为可由用户自由指定的语言条件变量**。
- 用户无法通过文本指令控制“先画什么、后画什么”，限制了草图生成的可控性和交互性。
- 本文希望**复用强大的预训练图像先验**（Qwen-Image-Edit-2509的潜在流匹配变换器），同时**使绘制顺序可被文本指令操控**。

## 2. 方法论

### 核心思想
将绘制顺序编码为图像的**颜色通道**（HSV），使顺序信息以图像形式存在，从而可被预训练的图像生成模型处理；再训练专用解码器将生成的图像**反向解码为有序矢量笔画**。

### 关键技术细节

1. **顺序-颜色编码（Order-as-Color Encoding）**
   - 全局弧长参数化：`a = ℓ / L ∈ [0, 1]`，表示整幅画的绘制进度。
   - 笔画内弧长：`u = ℓ_i / ℓ_i(终点)`，表示在该笔画内部的进度。
   - HSV编码：
     - **H（色相）** = `a × 342/360`（红色到紫色渐变，对应全局顺序）
     - **S（饱和度）** = 1（墨迹掩码）
     - **V（明度）** = `1 − u/2`（笔画内进度，从亮到暗渐变）
   - 背景为纯白 `HSV(0, 0, 1)`。
   - 结果：**单像素宽度的折线图**（不含画笔宽度），经VAE编码进入潜在空间。

2. **顺序原生解码器（Order-Native Decoder）**
   - 基于Qwen-Image的VAE解码器，**冻结编码器，微调解码器**并新增预测头。
   - 解码器主干输出金字塔特征（全分辨率、4×、16×），拼接后通过卷积层输出**10个通道**：
     - 1通道：全局弧长 `a′`（L1回归）
     - 1通道：前景logit `m′`（二值分割，BCE损失）
     - 8通道：实例嵌入 `e′`（用于笔画聚类，Push-Pull判别损失）
   - 像素重建分支保留，以保持图像质量。
   - 联合损失：前景加权L1 + LPIPS感知损失 + 弧长L1 + 掩码BCE + 嵌入Push-Pull。

3. **生成模型（DiT + LoRA）**
   - 基座：Qwen-Image-Edit-2509（潜在流匹配变换器）。
   - 使用**秩64的LoRA**微调，训练目标为标准潜在流匹配损失。
   - 条件输入：文本描述 或 参考图像（来自经顺序-颜色编码的中间表示）。
   - 训练数据采用**顺序排列增强**：保留区域内顺序，打乱区域间顺序，并程序化生成匹配的文本描述（如“先画box1左侧，再画box2，再回到box1右侧”）。

4. **矢量恢复流水线（后处理）**
   - 对预测嵌入 `e′` 用**HDBSCAN**聚类，得到笔画实例。
   - 按预测弧长 `a′` 的均值排序。
   - 每个聚类内用**最近邻游走**连接前景像素，分割为子段再合并。
   - **Ramer-Douglas-Peucker简化**（epsilon=0.5像素）。
   - 最终输出：带全局弧长排序的折线序列。

### 算法流程（文字版）
1. 输入：条件图像 `c` + 文本指令 `q`（或仅文本）
2. 生成：DiT在潜在空间中采样，得到中间表示潜码 `\hat{z}`
3. 解码：顺序原生解码器输出弧长场 `a′`、掩码 `m′`、嵌入 `e′`
4. 聚类：HDBSCAN对 `e′` 聚类，得到笔画实例
5. 排序：按 `a′` 均值对实例排序
6. 追踪：最近邻游走将前景像素转为折线
7. 简化：RDP简化，输出有序矢量笔画

## 6. 主要结论与发现

1. **顺序是语言可写的**：同一输入图像，仅改变文本指令即可使预测顺序在全范围摆动（Kendall τ从0.449→−0.267），几何形状完全不变。
2. **图像先验成功保留**：在QuickDraw 50类上CLIP Top-1达0.75（CFG=7.5），证明模型仍具备强大的零样本文本到草图生成能力。
3. **顺序控制粒度受限**：
   - 区域级指令：τ ≈ 0.84（高遵从度）
   - 部件级指令：τ ≈ 0.46（显著下降）
   - 阶段级指令：τ ≈ 0.44
   - 区域内顺序：τ ≈ 0.08–0.28（近乎随机）
4. **解码器提升显著**：弧长L1比冻结解码器降低**9–19倍**，Spearman相关系数≥0.994。
5. **矢量化解码存在碎片化**：恢复笔画数是真实的**1.6–2.5倍**，笔画被切分为多段。
6. **域外泛化能力有限**：对QuickDraw的Kendall τ仅0.56（解码器上界），复杂真实线稿的顺序控制尚停留在定性验证。

## 7. 方法优点

1. **范式创新**：逆转传统逐笔生成思路，首次将绘制顺序作为**可独立操控的二维场**显式预测，而非模型内部隐式属性。
2. **重用强大图像先验**：巧妙地将顺序编码为颜色，使现有预训练图像生成模型（Qwen-Image）可直接复用，无需从头训练大规模生成器。
3. **文本可控性强**：顺序控制通过自然语言指令实现，人机交互友好。
4. **高质量训练数据**：47,318张专业艺术家手绘图，质量远超现有涂鸦数据集，使模型有能力学习复杂绘制逻辑。
5. **完备的损失设计**：联合优化像素重建、弧长回归、分割掩码、实例嵌入，解码器各输出相互增强。
6. **评价体系严谨**：引入解码器上界、几何启发式基线、随机/反转控制等多层基准，可清晰定位各环节损失来源。

## 8. 不足与局限

1. **顺序控制粒度不足**：
   - 无法控制**笔画内顺序**（within-stroke order，τ≈0.05–0.28）。
   - 对“先画A再画B”中A/B的出现顺序敏感：若文本描述顺序与指令冲突，遵从度从0.78降至0.47。
   - 尾部指令（如“最后画X”）几乎完全丢失。
2. **矢量恢复质量损失**：
   - 笔画碎片化严重（1.7–2.5×真实笔数）。
   - 丢弃了真实绘制中的时间、压力、倾斜、画笔宽度信息，输出仅为1像素宽中心线。
3. **无指令时无可靠先验**：
   - 由于训练时打乱了顺序与几何的关联，无文本指令时模型的全局顺序优先验几乎不存在（τ≈0.096–0.308，与几何启发式相当）。
4. **域外泛化受限**：
   - 在QuickDraw等稀疏短笔画数据集上顺序恢复显著下降（τ≈0.56上界）。
   - 对真实复杂线稿的顺序控制仅做了定性展示，缺乏定量评估。
5. **计算成本高**：
   - 2,848 GPU小时（32×H100）的微调成本，对一般研究组不友好。
6. **训练/推理复杂**：
   - 流水线包含VAE编解码、DiT采样、HDBSCAN聚类、最近邻游走、RDP简化等多个阶段，端到端并非完全可微。
7. **评价聚焦顺序，忽视视觉质量**：
   - 未系统评估生成草图的视觉保真度（FID、人类偏好等），仅依赖CLIP识别率作为间接指标。
