## Abstract
High-fidelity image generation faces a trade-off between speed and quality. Diffusion models produce strong visuals but require costly iterative sampling. Existing efficient methods mainly distill pretrained models into few-step samplers, a challenging process that depends heavily on teacher-model quality. In this paper, we introduce XYZFlow, a framework that rethinks efficient generation through multidimensional scaling of flow matching. Unlike single-step mappings, XYZFlow enhances expressivity by making probability paths more identifiable and learnable through structured multidimensional conditioning. We view autoregressive modeling as implicit flow straightening, where richer context reduces trajectory ambiguity. XYZFlow realizes this idea through two orthogonal dimensions: temporal scaling, which uses non-Markovian conditioning on the full denoising history; and spatial scaling, enabled by Next Shortcut Prediction, which sequentially generates patches using preceding patches' denoising trajectories as priors. Experiments show that XYZFlow achieves state-of-the-art performance, with 7.2-8.5X teacher speedups and competitive FID, while Next Shortcut Prediction delivers superior quality-latency trade-offs over model scaling or step reduction.

## 2. 论文提出的方法论

### 核心思想

XYZFlow 沿两个正交维度扩展流匹配：
- **时间维度（Temporal Scaling）**：将去噪从马尔可夫变为非马尔可夫，每个流步骤都基于完整的历史状态进行条件化，利用 KV cache 作为条件锚点。
- **空间维度（Spatial Scaling）**：提出“Next Shortcut Prediction”，将图像划分为网格（如 2×2），按序逐块生成，并将前序 patch 的完整去噪轨迹（而非仅最终输出）作为后续 patch 的强有力先验。

### 关键技术细节

1. **自回归建模即流增强**：将图像划分为 patches $\langle x_1, x_2, \ldots, x_P \rangle$，自回归生成遵循链式法则 $p(x_1,\ldots,x_P)=\prod_{p=1}^P p(x_p|x_1,\ldots,x_{p-1})$。不断扩展的上下文构成一组逐步增强的约束，可降低条件分布的方差，使概率流路径更直、更确定。

2. **时间条件化（Intra-patch Trajectory Conditioning）**：对于 patch $x_p$，在时间 $t$ 的条件信号是其从生成开始到当前时间（不含）的完整状态轨迹 $H_t^p = \{x_\tau^p\}_{\tau=0}^{t-\Delta t}$。损失函数为：
   $$L_p^{\text{temp}} = \mathbb{E}_{t, x_0^p, x_1^p} \|v_\theta(x_t^p | t, H_t^p) - (x_1^p - x_0^p)\|^2$$
   这种自条件化通过自注意力机制充当强生成先验。

3. **空间条件化（Inter-patch Trajectory Conditioning）**：每个 patch 的生成条件化为所有先前 patch 的完整轨迹 $T_{<p} = \{\tau_1, \tau_2, \ldots, \tau_{p-1}\}$，其中 $\tau_i = \{x_i^t\}_{t=0}^1$。条件化于完整轨迹而非仅最终状态提供了显著更强的约束。

4. **Next Shortcut Prediction 训练目标**：定义渐进式去噪调度，每个 patch $p$ 被分配的步数随序列位置递减：
   $$T(p) = T_{\text{full}} - \Delta T \cdot (p - 1), \quad T(p) \geq T_{\min} > 0$$
   训练目标为教师模型轨迹蒸馏：
   $$p(x_0^p | T_{<p}) = p_{\text{prior}}(x_{T(p)}^p) \times \prod_{t=1}^{T(p)} p(x_{t-1}^p | x_{T(p):t}^p, T_{<p})$$
   学生网络通过一个欧拉步骤逼近映射函数：
   $$x_{t-1}^p = G(x_{T(p):t}^p, T_{<p}, t) = x_t^p + (\gamma(t-1) - \gamma(t)) \cdot v_\theta(x_{T(p):t}^p, t, T_{<p})$$
   完整训练目标为：
   $$L_{\text{NextShortcut}} = \mathbb{E}_{p \sim [1,P]} \left[ \sum_{t=1}^{T(p)} \| G_\theta(x_{T(p):t}^p, t, T_{<p}) - x_{t-1}^p \|_2^2 \right]$$
   Transformer 通过块级因果注意力掩码实现所有 $t$ 的同时计算。

5. **推理过程**：第一个 patch 使用完整步数 $T(1)=T_{\text{full}}$ 生成，建立稳健锚点；后续每个 patch $p \geq 2$ 自回归生成，从 $x_{T(p)}^p \sim p_{\text{prior}}$ 开始，每一步基于完整历史预测 $\hat{x}_{t-1}^p = G_\theta(\hat{x}_{T(p):t}^p, t, T_{<p})$，历史预测信息通过 KV cache 高效管理。

## 6. 论文的主要结论与发现

1. **XYZFlow 在效率-质量权衡上达到 SOTA**：Base 模型（172M）达到 36.1× 教师加速，FID 1.63（w/ GAN），匹配 676M 参数 MeanFlow-XL/2+ 的推理速度（0.018s）且 FID 更优
2. **多维条件化有效直化概率流**：后续 patch 的去噪路径更直，路径直度度量 $S$ 随生成序列位置递减，验证了强上下文条件化能有效直化流
3. **Next Shortcut Prediction 实现效率提升**：渐进式 5→4→3→2 调度以 30% 更少步数（14 vs 20）达到与常数 5 步方案几乎相同的质量（FID 1.63 vs 1.63）【8†L0】
4. **框架对教师质量鲁棒**：即使在弱教师（DiT/XL-2，25 步）下，XYZFlow-B 仍保持强劲性能（FID 3.85 w/o GAN，1.74 w/ GAN），而标准 5 步蒸馏急剧退化至 FID 8.97【7†L0】
5. **Full History Guidance 是最关键组件**：移除它导致 FID 退化约 0.5【7†L0】
6. **Cell size 存在最优值**：$k=8$（8×8 tokens）时性能最佳（FID 2.02），过小或过大均导致性能下降【8†L0】
