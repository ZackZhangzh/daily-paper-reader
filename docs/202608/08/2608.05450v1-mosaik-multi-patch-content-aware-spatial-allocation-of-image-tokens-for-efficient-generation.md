## 摘要
像素空间扩散模型通过在图像空间中直接生成，避免了潜在扩散模型的重建瓶颈。然而，由于自注意力的二次复杂度，其远高于潜在模型的令牌数量导致生成成本昂贵。现有的若干效率提升方法通过在选择性的去噪步骤中使用更大的图像块，从而用更少的令牌表示图像，以此降低计算成本。然而，每一步仍在整个图像上统一采用单一图像块尺寸，忽略了不同区域在粗化时承受不同的保真度损失。我们提出MOSAIK，一个损伤引导框架，可在不同区域和去噪步骤间灵活调整图像块尺寸。MOSAIK改造了PixelDiT骨干网络，以生成任意异质的图像块布局，同时一个轻量级预测器利用中间去噪特征估计粗化各区域所造成的保真度损失。在给定令牌预算下，我们的损伤引导布局预测器为敏感区域分配精细图像块，其余区域则使用粗放图像块。值得注意的是，在将FLOPs减少70%、令牌数量减少83%的同时，MOSAIK在GenEval上达到了与完整计算量PixelDiT相当的性能，其DPG-Bench分数仅下降1.0点。与包括时间图像块调度和特征缓存等多种效率范式相比，我们的方法在中等预算下展现出极具竞争力的性能，并在高度受限的计算场景中持续优于这些基线方法。

## Abstract
Pixel-space diffusion models avoid the reconstruction ceiling of latent diffusion models by generating directly in image space. However, their substantially higher token count makes generation expensive due to the quadratic complexity of self-attention. Several existing efficiency methods reduce this cost by using larger patches at selected denoising steps, thereby representing the image with fewer tokens. Yet, each step still uses a single patch size uniformly across the entire image, overlooking that different regions suffer different fidelity losses when coarsened. We introduce MOSAIK, a damage-guided framework that varies patch size across regions and denoising steps. MOSAIK adapts the PixelDiT backbone to generate arbitrary heterogeneous patch layouts, and a lightweight predictor uses intermediate denoising features to estimate the fidelity loss caused by coarsening each region. Given a token budget, our damage-guided layout predictor assigns fine patches to sensitive regions and coarse patches elsewhere. Remarkably, while reducing FLOPs by 70% and token count by 83%, MOSAIK matches the full-compute PixelDiT on GenEval and its DPG-Bench score drops by only 1.0 point. Compared to diverse efficiency paradigms, including temporal patch scheduling and feature caching, our approach delivers highly competitive performance at moderate budgets and consistently outperforms these baselines in highly constrained compute regimes.

## 一、核心问题与研究动机

### 1.1 背景

扩散模型已成为高保真图像生成的主流范式。为控制计算成本，多数扩散模型（如潜在扩散模型 LDM）在预训练 VAE 压缩的潜在空间中运行。然而，这种效率提升伴随着固有的**重建上限（reconstruction ceiling）**：VAE 丢弃的信息（尤其是细粒度和高频空间细节）无法被扩散模型恢复。

近年来的像素空间扩散模型（PDM）通过在图像空间中直接生成来规避这一问题。但这带来了新的瓶颈：原始像素空间中的令牌数量远高于潜在空间，而自注意力的二次复杂度使生成成本急剧上升。

### 1.2 核心问题

现有效率提升方法（如在不同去噪步骤或网络深度使用不同图像块大小）虽然在时间或深度维度上进行了自适应，但**每一步仍在整个图像上统一采用单一图像块尺寸**。这种做法忽略了图像不同区域对粗化操作的敏感度差异——主体边缘等敏感区域粗化后保真度损失大，而平滑背景区域则可以承受更大程度的粗化。

### 1.3 研究目标

MOSAIK 提出**空间自适应的图像块分配（spatially adaptive patchification）**：在敏感区域保留小块，在其他区域分配大块，从而在保证视觉质量的同时大幅降低计算成本。


## 二、方法论

### 2.1 整体框架

MOSAIK 的核心思想是**将异构图像块布局的执行与决定空间分配的策略解耦**。通过三阶段训练流水线实现：

### 2.2 Stage 1：多图像块流畅性（Multi-Patch Fluency）

**架构修改**：
- 冻结 PixelDiT 骨干网络权重，在 DiT 模块中注入低秩适配（LoRA，秩为32）
- 为 p32 和 p64 引入独立的 tokenizer
- 为每个 token 添加可学习的图像块尺寸嵌入
- 引入可学习的像素重排（pixel-shuffle）条件上采样器，将粗粒度 DiT 表征提升至 p16 网格

**训练目标**：通过自蒸馏，使多图像块生成器的速度预测匹配冻结的 p16 教师网络：

$$\mathcal{L}_{\text{self-distill}} = \mathbb{E}_{x_t,\sigma,y,P} \left[ \left\| v^P_\theta(x_t, \sigma, y) - v^{16}_{\text{teacher}}(x_t, \sigma, y) \right\|_2^2 \right]$$

### 2.3 Stage 2：混合图像块适应（Mixed-Patch Adaptation）

**位置编码处理**：由于异构图像块中不同尺寸的 token 不再位于统一的令牌网格上，MOSAIK 将每个 token 锚定到其图像块在归一化 p16 坐标框架中的几何中心。

**训练策略**：在随机采样的异构图像块布局上训练生成器：
- 60% 概率使用混合布局（覆盖广泛的令牌预算范围）
- 40% 概率使用均匀布局（保留 Stage 1 学到的均匀配置性能）

### 2.4 Stage 3：损伤引导的布局预测器（Damage-Guided Layout Predictor）

**核心洞察**：空间粗化造成的退化本身就是一个直接的分配信号——对粗化更敏感的区域应获得更精细的分辨率。

**损伤目标计算**：在去噪步骤 t，计算多图像块生成器在均匀 p64 布局下的预测与冻结 p16 教师预测之间的平方差，然后在 64×64 区域上做平均池化：

$$\tilde{d}_t = \text{AvgPool}\left( \left\| v^{64}_\theta(x_t, \sigma, y) - v^{16}_{\text{teacher}}(x_t, \sigma, y) \right\|_2^2 \right)$$

**轻量级预测器**：为避免推理时二次前向传播抵消计算节省，训练一个轻量级卷积网络 $f_\phi$（约 163 万参数），从 DiT 第 6 块的中间激活、噪声水平 σ 和池化文本嵌入中回归损伤图，使用 Huber 损失以鲁棒处理异常值。

**推理时分配策略**：
- 所有区域初始化为 p64
- 考虑两级细化：p64→p32（+3 tokens，优先级 $d_t^r/3$）和 p32→p16（+12 tokens，优先级 $d_t^r/12$）
- 迭代应用在剩余预算内优先级最高的可用细化
- 训练与预算无关，同一模型可在任意推理预算下运行

## 七、方法亮点与优势

1. **空间自适应**：首次在像素空间扩散模型中实现**逐区域**的图像块尺寸分配，而非全局统一，更符合图像内容的空间异质性。

2. **损伤引导机制**：将图像块分配形式化为**损伤预测问题**，从中间特征直接估计粗化损失，信号透明且可解释。

3. **训练与推理解耦**：布局预测器离线训练，推理时仅增加 2.0 ms/步的开销【B.1 节】，且训练与预算无关，同一模型可服务于任意计算预算。

4. **与现有方法正交兼容**：可无缝叠加在 TeaCache、TaylorSeer 等缓存方法之上，进一步拓展计算-质量前沿。

5. **强大的稳定性**：在极宽的计算预算范围内（25%–83% 令牌减少）保持几乎恒定的生成质量。

6. **充分的实验验证**：涵盖多基准、多基线、多预算、多消融，实验设计严谨客观。


## 八、不足与局限

1. **算力信息不透明**：未明确披露 GPU 型号、数量和训练总时长，不利于复现和成本评估。

2. **PDM 依赖**：方法构建在 PixelDiT 这一特定像素空间扩散模型之上，泛化到其他 PDM 架构（如 DiP、DeCo、HyperDiT）的迁移成本未经验证。

3. **固定模块开销**：PiT 像素解码器不随图像块尺寸缩放，占 p16 步骤的 21%，构成硬性的 wall-clock 下限（约 4.4s/图）【Table 4】【B.1 节】。
