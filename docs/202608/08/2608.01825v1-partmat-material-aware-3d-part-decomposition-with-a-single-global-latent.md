## 摘要
近年来，部件级3D生成因能够产生结构化和可编辑的3D资产而受到日益关注。然而，现有方法通常根据功能语义而非实际3D应用（如室内设计）所需的可编辑材质边界（如织物、木材、金属）来分解物体。此外，当前方法常独立生成各部件，导致计算成本随部件数量线性增长。为解决这些局限，我们提出PartMat，一种高效的材质感知3D部件分解流水线，利用单一全局潜变量表示多部件几何。给定参考图像和单个完整物体几何，PartMat将物体沿材质边界分解为多个部件。首先，我们提出PartVAE以学习这种统一表示，并在单次前向传递中解码所有材质部件，从而将推理成本与部件数量解耦。其次，基于该表示，我们训练扩散模型用于部件生成，并通过强化学习进行精调，以实现准确的材质分配和重叠抑制。最后，为恢复细粒度几何细节，我们引入了一种带有部件注意力的稀疏体素流匹配模型用于几何后处理。大量实验表明，PartMat在材质感知分解准确度上显著优于现有基线，同时达到相当的几何质量，并保持高效的推理性能。

## Abstract
Part-level 3D generation has recently attracted increasing attention for producing structured and editable 3D assets. However, existing methods typically decompose objects according to functional semantics rather than the editable material boundaries (e.g., fabric, wood, metal) required in practical 3D applications such as interior design. Additionally, current methods often generate parts independently, causing computational costs to scale linearly with the part count. To address these limitations, we present PartMat, an efficient material-aware 3D part decomposition pipeline that represents multi-part geometry with a single global latent. Given a reference image and a single whole-object geometry, PartMat decomposes the object into parts that follow material boundaries. First, we propose PartVAE to learn such a unified representation and decode all material parts in a single forward pass, thereby decoupling inference cost from the number of parts. Second, with this representation, a diffusion model is trained for part generation and refined via reinforcement learning for accurate material assignment and overlap suppression. Finally, to recover fine-grained geometric details, we introduce a sparse-voxel flow-matching model with part attention for geometry post-processing. Extensive experiments demonstrate that PartMat significantly outperforms existing baselines in material-aware decomposition accuracy and achieves comparable geometric quality, while maintaining efficient inference.

**研究动机**

现有3D部件级生成方法存在两大核心局限：

- **分解依据不匹配实际需求**：现有方法主要根据**功能语义**（如椅背、椅座、椅腿）或几何结构来分解物体。然而，室内设计、仿真规划等实际应用需要的是按**可编辑材质边界**（如织物、木材、金属、玻璃等）进行分解，以便独立替换部件、分配密度/摩擦系数等物理属性。功能部件与材质边界并不一一对应——同一功能部件可能包含多种材质，而同一材质的多个不连续区域可能需要统一编辑。

- **计算成本随部件数线性增长**：现有部件级方法通常独立编码/生成每个部件，潜变量大小和解码成本随部件数量增长，导致包含大量材质区域的物体推理效率低下。

**整体含义**

PartMat提出了**首个用单一全局潜变量表示多部件几何**的材质感知3D部件分解框架。给定参考图像和完整物体几何网格，PartMat将物体沿材质边界分解为多个独立可编辑的部件网格，且推理成本与部件数量解耦。

## 2. 方法论

PartMat采用**三阶段流水线**：

### 阶段一：PartVAE——全局部件编码与解码

PartVAE基于Hunyuan3D 2.1 ShapeVAE的变分编码器-解码器Transformer架构，核心设计包括：

- **部件感知点编码器**：从物体表面采样点，输入包括位置、法向、材质部件ID和锐边指示符。编码器通过交叉注意力和Transformer层将点云聚合为潜变量 **z ∈ R^L×d**，该潜变量被所有部件共享。

- **多头SDF解码器**：一个线性头预测 **K=32** 个通道的SDF值，每个通道对应一个材质部件。解码成本固定，与物体实际部件数 **M** 无关。

- **训练损失**：`L_VAE = L_recon + L_suppress + λ_KL L_KL`。其中有效部件通道受MSE和L1重建损失监督；不存在的部件通道被抑制在负SDF区间内（`[-1.0, -0.1]`），确保其不产生零等值面。

### 阶段二：PartDiT + 强化学习对齐

**生成**：冻结PartVAE，训练条件扩散模型PartDiT。DINOv2编码参考图像，PartVAE编码器提取完整物体几何的潜变量。PartDiT通过流匹配目标 `L_FM = E[||v_θ(z_t, t; c) - (z_1 - z_0)||²]` 训练。

**强化学习精调**：提出**可微SDF奖励**，直接在隐式SDF空间计算，无需显式解码网格：
- **匹配奖励** `R_match`：计算预测部件与目标部件之间的软 occupancy 相似度，通过可微软分配处理部件顺序不一致。
- **重叠惩罚** `R_overlap`：惩罚不同预测部件同时占据同一空间位置。
- 总奖励 `R_sdf = λ_match R_match + λ_overlap R_overlap`。

采用直接梯度RL对齐，将可微SDF奖励反向传播至PartDiT。

### 阶段三：部件感知稀疏几何精化

PartVAE的紧凑潜变量会平滑薄结构和材质界面，因此引入精化阶段：

- 将粗部件编码到**固定稀疏体素支撑**上。
- **部件注意力**机制：同一部件内的token执行自注意力，防止部件身份丢失；全局自注意力跨部件传播上下文信息。
- 训练稀疏潜变量流匹配模型，目标 `L_HR = E[||H_ω(X_t, t, c_I, U) - (X_1 - X_0)||²]`。

## 7. 优点（亮点）

- **首创单一全局潜变量表示多部件几何**：将推理成本与部件数量解耦，解决了长期存在的效率瓶颈。
- **可微SDF奖励**：在隐式空间直接计算RL奖励，避免了显式解码网格的高昂成本，使RL精调变得可行。
- **部件注意力机制**：在精化阶段平衡了“保持部件身份”与“跨部件上下文通信”的矛盾。
- **端到端材质感知**：不同于“先纹理生成再分割”的级联方案，PartMat直接生成带材质部件ID的几何，避免了错误传播。
- **大规模训练数据**：使用约30万带材质标注的物体，为模型提供了充足监督信号。

- **微小细节恢复仍有限**：论文承认紧凑潜变量对极细小结构的重建仍有挑战，需要更强的精化模块。
