## 摘要
流匹配假设训练数据是完全观测的，而现实世界中的许多应用很少能提供这样的数据。我们提出了缺失数据流匹配，该方法将训练样本中缺失的坐标视为潜变量，并对它们可能取的值上的流匹配损失进行平均。我们首先证明该修正是精确的而非近似的。在完全随机缺失且存在真实补全的情况下，不完全数据目标等于完全数据目标，因此缺失性并不改变流匹配所学习的内容，所有困难都转移到了补全模型上。随后，我们的有限样本分析回答了该算法遗留的设计问题，而答案并非直觉所提示的那样。缺失性会转移而非增加估计量的方差，每个样本一次补全即可精确匹配完全数据的方差，并且在固定评估预算下，一次补全是最优的。学习到的补全模型贡献了一个不可约的单一偏差，我们通过其与真实补全定律之间的期望条件Wasserstein距离来界定该偏差。实验在数值上验证了理论预测，表明导致生成分布崩溃的是确定性而非冻结的插补，并将我们的方法与强大的经典和深度插补基线在真实表格数据上进行了对比。

## Abstract
Flow matching assumes fully observed training data, which many real-world applications rarely provide. We propose Missing-Data Flow Matching, which treats the missing coordinates of training samples as latent variables and averages the flow matching loss over the values they could take. We first prove the correction is exact rather than approximate. Under missing completely at random with true completions, the incomplete-data objective equals the complete-data objective, so missingness changes nothing about what flow matching learns and the entire difficulty relocates to the completion model. Our finite-sample analysis then answers design questions that the algorithm leaves open, and the answers are not the ones intuition suggests. Missingness transfers estimator variance rather than adding it, one completion per example already matches complete-data variance exactly, and under a fixed evaluation budget one completion is optimal. A learned completion model contributes a single irreducible bias, which we bound by its expected conditional Wasserstein distance to the true completion law. Experiments numerically validate the theoretical predictions, show that deterministic rather than frozen imputation is what collapses the generated distribution, and place our method alongside strong classical and deep imputation baselines on real tabular data.

## 1. 论文的核心问题与整体含义

**研究动机与背景**

标准流匹配（Flow Matching）是一种有效的生成建模方法，通过学习一个将基础分布（如高斯噪声）运输到数据分布的时间依赖向量场来生成新样本。但其核心假设是**训练数据完全可观测**，而现实世界中的数据（如医疗记录、传感器读数、调查问卷）普遍存在缺失值。

**核心问题**

当训练数据存在缺失时，标准流匹配无法构建插值路径所需的完整终点（endpoint），也就无法计算回归目标（即终点与起点的差值）。简单粗暴的确定性插补（如用条件均值填充）会将原本具有多样性的缺失值压缩为单个点，导致生成模型丢失条件方差，产生分布坍塌。

**整体含义**

本文提出的**缺失数据流匹配（Missing-Data Flow Matching, MDFM）** 不是简单地“填补”缺失值，而是将缺失坐标视为**潜变量**，在训练时对缺失部分所有可能取值上的损失进行平均。其核心洞察是：在完全随机缺失（MCAR）条件下，这种处理方式与使用完整数据训练**精确等价**，缺失本身并不改变流匹配的学习目标，只是把“补全”这个难题转移给了补全模型。

## 2. 方法论

**核心思想**

MDFM 的核心思想是**不承诺单一值，而是对条件分布进行采样平均**。对于每个不完整观测 `O = (Λ, X_Λ)`（其中 `Λ` 为观测到的坐标集合，`X_Λ` 为观测值），从真实条件分布 `p⋆(x_{-Λ} | x_Λ)` 中采样缺失部分 `X_{-Λ}`，形成完整终点 `X_1 = (X_Λ, X_{-Λ})`，然后计算标准流匹配损失。训练目标为：

```
L_MDFM(θ) = E_Λ E_{X_Λ} E_{X_{-Λ} ∼ p⋆(·|X_Λ)} E_{X_0, T} [ ℓ_θ(X_0, X_1, T) ]
```

其中 `ℓ_θ` 为标准流匹配的每样本损失。

**关键技术细节**

- **Oracle 等价性（Theorem 4.2）**：在 MCAR 假设下，若补全来自真实条件分布 `p⋆(x_{-Λ} | x_Λ)`，则 MDFM 目标与完整数据流匹配目标**逐点相等**：`L_MDFM(θ) = L_FM(θ)`。这不是近似，而是精确相等。
- **梯度一致性（Corollary 4.3）**：由于目标函数相等，两者的梯度也在可微点处完全一致。
- **学习补全模型**：实践中用参数化模型 `q_φ(x_{-Λ} | x_Λ, Λ)` 代替真实条件分布，在独立辅助样本上通过自监督掩码训练。
- **有限样本估计器**：用 `n` 个不完整样本、每个样本 `K` 次补全来估计目标：
  ```
  ̂L^φ_{n,K}(θ) = (1/n) Σ_i (1/K) Σ_k ℓ_θ(X^{(i,k)}_0, ̃X^{(i,k)}_1, T^{(i,k)})
  ```
  

**算法流程**

1. 在独立辅助样本上训练补全模型 `q_φ` 并冻结
2. 对每个不完整样本，从 `q_φ` 中采样 `K` 次缺失部分
3. 结合观测部分形成 `K` 个完整终点
4. 对每个终点独立采样基础点 `X_0` 和时间 `T`
5. 计算流匹配损失并平均，更新向量场参数 `θ`

## 6. 主要结论与发现

1. **Oracle 修正是精确的**：在 MCAR 下，MDFM 目标与完整数据目标相对差距 < 0.5%，梯度余弦与完整数据自身噪声基线一致。

2. **缺失转移方差而非增加方差**：定理 5.1 证明，缺失带来的条件补全方位差 `σ²_{θ,miss}` 可通过多次补全平均来降低，总方差上界与缺失率无关。

3. **一次补全即最优**：在固定评估预算（总损失评估次数 `N = nK`）下，`K=1` 时估计量方差最小。实验验证了该结论（图 6）。

4. **确定性插补导致分布坍塌**：条件均值插补仅恢复了 64% 的真实条件标准差，分布误差是随机策略的 3 倍；而所有随机策略（无论是否冻结）均恢复了 97% 以上。

5. **MDFM 在真实数据上竞争力强**：在 7 个 UCI 数据集上，MDFM 在协方差误差上排名第一（0.305），在 sW2、能量距离、MMD 上排名第二，仅次于 MICE。

6. **补全质量决定误差下限**：学习补全模型的偏差由其与真实条件分布的期望 Wasserstein-1 距离上界控制：`|L_φ - L_FM| ≤ L_g · E_O[W_1(q_φ, r⋆_Λ)]`。
