## 摘要
即时重建是机器人和自主导航中许多应用的关键需求。变分贝叶斯高斯泼溅（VBGS）利用坐标上升变分推理（CAVI）无需重放缓冲区即可实现连续学习，但其对每个帧的所有观测点进行迭代，使得在严格的内存和延迟要求下无法满足实时使用。我们提出了ImprovedVBGS，一种用于即时连续重建的加速框架。这主要通过（i）空间截断变分推理和（ii）改进的重分配来实现，后者利用前向传播和截断，并消除了低效的动态重编译。在NeRF合成数据集上，我们在RTX 3070 Ti上将平均每帧延迟从约84.0秒降低到约0.050秒，实现了1680倍的加速，同时保持了重建质量。

## Abstract
On-the-fly reconstruction is a key requirement for many applications in robotics and autonomous navigation. Variational Bayes Gaussian Splatting (VBGS) enables continual learning without replay buffers using Coordinate Ascent Variational Inference (CAVI), but its per-frame iterations over all observed points make it too slow for real-time use with strict memory and latency requirements. We present ImprovedVBGS, an accelerated framework for on-the-fly continual reconstruction. This is achieved primarily through (i) spatially truncated variational inference, and (ii) improved reassignment that uses forwarding, truncation and eliminates wasteful dynamic recompilation. On the NeRF synthetic dataset, we reduce mean per-frame latency from ~84.0 s to ~0.050 s on an RTX 3070 Ti, a 1680x speed-up while maintaining reconstruction quality.

## 1. 论文的核心问题与整体含义

- **背景与动机**：在机器人、自主导航等场景中，**即时（on-the-fly）三维重建**是关键需求。传统的3D高斯泼溅（3DGS）优化假设所有训练视图同时可用，在连续学习（continual learning）场景下，新数据会覆盖旧参数，引发**灾难性遗忘**（catastrophic forgetting）。现有缓解策略（如重放缓冲区）会随观测视图增多而显著增加内存与计算开销，不适合资源受限场景。
- **VBGS的局限**：变分贝叶斯高斯泼溅（VBGS）通过坐标上升变分推理（CAVI）实现了无需重放缓冲区的连续学习，其更新具有**顺序不变性**，天然抗灾难性遗忘。但其**每帧需对所有观测点迭代**（复杂度O(nK)），在严格内存与延迟约束下无法满足实时使用；同时VBGS参数数量是传统3DGS的两倍以上（29 vs 14），内存占用高。
- **核心问题**：如何**大幅降低VBGS的每帧推理延迟**，使其在消费级硬件上也能实现实时连续重建，同时保持重建质量。

## 2. 方法论：核心思想与关键技术

ImprovedVBGS在复现Zaino等人【11】的融合统计量与混合精度优化的基础上，新增三项核心加速技术：

### （1）空间截断变分E步（Spatially Truncated Variational E-step）

- **核心思想**：VBGS的E步需要为每个数据点计算所有K个分组的分配期望，构成主要瓶颈。由于**空间似然集中在邻近均值上**，不必评估所有分组。
- **实现方式**：每帧构建空间均值{μₛ,ₖ}的**KD-tree**，对每个点查询**C个最近邻**分组的索引，仅在该子集上计算对数得分log γ̂ₙ,ₖ，然后形成软责任Rₙ = softmax(log γ̂ₙ)和ELBOₙ = logsumexp(log γ̂ₙ)。
- **效果**：将计算从全量K缩减到常数C，大幅降低E步开销。

### （2）改进的重分配策略（Improved Reassignment）

- **重分配的必要性**：在随机初始化且数据统计未知的连续学习设定中，需要将**未使用的分组**重新定位到**建模较差的区域**。未使用分组通过Dirichlet后验参数αₖ（低于先验阈值）识别，每次取αₖ最低的5%分组进行重分配。目标位置选取当前批次中**每点ELBO最低**的若干点。
- **截断重分配**：直接复用E步已计算的ELBO值，避免密集的ELBO重扫描。
- **重分配前向传递**：调整步骤顺序，将ELBO值从fit步骤直接前向传递到重分配步骤，**以微小的PSNR下降换取更低的延迟**。

### （3）静态张量填充（Static Tensor Padding）

- **问题**：重分配数量n_reassign每帧动态变化，导致JAX**每帧重新编译**执行图，产生大量开销。
- **解决方案**：将重分配索引数组填充到**静态编译时形状**n_max = ⌊f·N⌋，彻底消除动态重编译。

### 算法流程概述

> 每帧输入：新批次数据X_B、当前模型M₀、候选索引C_B
> 1. **空间截断E步**：对每个点xₙ，基于KD-tree取C个近邻分组，计算截断后的log γ̂ₙ、Rₙ、ELBOₙ
> 2. **M步**：基于截断责任更新各分组的充分统计量（融合内核实现）
> 3. **重分配**（若启用）：复用ELBO值，将低αₖ分组移至低ELBO区域（静态填充避免重编译）

## 6. 论文的主要结论与发现

- **核心结论**：ImprovedVBGS在**保持重建质量（PSNR≈21.42 dB）** 的前提下，将VBGS的每帧延迟从**84.0秒降至约0.050秒（最优配置）**，实现了**1680倍加速**。
- **关键发现**：
  - **空间截断E步**是最大的加速来源：单独应用即将延迟从84.0秒降至3.39秒。
  - **大批量（250k）** 进一步将延迟降至0.050秒。
  - **重分配是新的瓶颈**：加入重分配后延迟反弹至18.1秒，截断重分配将其降至0.373秒，静态填充进一步降至0.131秒。
  - **重分配前向传递**以**0.20 dB的PSNR下降**换取额外延迟降低（0.131→0.107秒）。
  - **混合精度在截断E步应用后不再带来显著收益**。
- **实践意义**：ImprovedVBGS使**无需重放的连续学习**在**消费级GPU（RTX 3070 Ti）** 上达到实用水平。
