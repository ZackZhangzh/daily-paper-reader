## 摘要
扩散变换器在图像生成任务上表现优异，但大多数工作于压缩潜空间。像素空间扩散避免了这种信息损失，然而现有方法将每个原始图像块映射为单个标记，迫使单一表示同时承担全局通信和细粒度细节处理。针对此问题，我们提出了一种新架构——\textbf{DuSPiT}，即\textbf{双分支子块像素变换器}（\textbf{Du}al-branch \textbf{S}ub\textbf{P}atch \textbf{Pi}xel \textbf{T}ransformer）。该模型将全局结构推理与局部外观建模相分离。DuSPiT采用紧凑的基础分支进行高效的全局推理，并并行使用一个高容量像素分支（按子块组组织）以保留细致外观，两个分支通过交叉注意力进行交互。实验结果表明，DuSPiT生成的图像具有更丰富的细节和更强的细粒度结构，同时相较于先前的像素空间扩散变换器实现了更优的质量-效率权衡。

## Abstract
Diffusion Transformers achieve strong image generation performance, but most operate in compressed latent spaces. Pixel-space diffusion avoids this information loss, yet existing approaches map each raw image patch to a single token, forcing one representation to handle both global communication and fine-grained details. We address this issue by proposing a new architecture, \textbf{DuSPiT}, a \textbf{Du}al-branch \textbf{S}ub\textbf{P}atch \textbf{Pi}xel \textbf{T}ransformer. This model separates global structural reasoning from local appearance modeling. DuSPiT uses a compact base branch for efficient global reasoning and a parallel, high-capacity pixel branch, organized into subpatch groups, to preserve detailed appearance, with the two branches interacting through cross-attention. Our results show that DuSPiT generates images with richer details and stronger fine-grained structures, while also achieving a better quality--efficiency trade-off than prior pixel-space diffusion transformers.

## 1. 论文的核心问题与整体含义

### 研究背景
- **扩散模型（Diffusion Models）** 已成为高质量图像生成的主流范式，其中 **扩散变换器（DiT）** 表现尤为突出。
- 主流系统（如 Stable Diffusion）采用 **潜在空间扩散（Latent Diffusion）** ，借助预训练的 VAE 将图像压缩到低维潜空间再进行扩散。这种方式虽然大幅提升了计算效率，但 **有损压缩会丢弃细粒度视觉信号**，如纹理细节、物体边缘锐度、文字图案等。

### 核心问题
- **像素空间扩散** 直接在原始图像域操作，避免了 VAE 压缩带来的信息损失，近年重新受到关注（如 JiT、PixelDiT、DeCo 等）。
- 但这类方法存在一个 **结构性的表征瓶颈**：每个图像块（Patch）被压缩为 **单个紧凑 token**，这个 token 必须同时承担两重任务：
  1. **全局推理**——通过自注意力建模跨 patch 的全局结构与语义关系；
  2. **局部外观建模**——保留 patch 内部的丰富细节。
- 这种单一表征的设计使得全局与局部需求相互冲突。简单地增加 token 宽度（嵌入维度）虽可缓解，但会带来参数和计算成本的急剧膨胀。

### 论文核心主张
- 像素空间扩散的核心挑战 **不在于模型宽度不足**，而在于 **缺少架构层面的分离**：应将 **全局 patch 级推理** 与 **局部 subpatch 级外观建模** 解耦为两条独立的表征路径。

> 这一主张构成了整篇论文的设计哲学基础。

## 2. 方法论：DuSPiT 的核心思想与关键技术

### 2.1 高层架构概览

DuSPiT 采用 **双分支并行架构**（如图 1 所示）：

| 分支 | 名称 | 嵌入维度 | 功能定位 |
|:---:|:---:|:---:|:---|
| **基分支（Base Branch）** | Patch Branch | $d_p$（较小，如 1024） | 高效全局推理：patch 间自注意力、结构语义建模 |
| **像素分支（Pixel Branch）** | Pixel Branch | $d_a \gg d_p$（如 3072） | 细粒度外观建模：保留纹理、边缘、色彩等高频信息 |

- 两分支通过 **交叉注意力（Cross-Attention）** 交互，基分支提供全局结构指导，像素分支从中吸收上下文用于外观细化。
- 最终 **去噪预测仅由像素分支生成**，基分支作为内部结构瓶颈，不参与最终输出。

### 2.2 Tokenization 与双分支表征

给定噪声图像 $x_t \in \mathbb{R}^{H \times W \times C}$，划分为 $P \times P$ 的非重叠 Patch。对第 $i$ 个 Patch：

$$ z_i = E_{\text{patch}}(x_t^{(i)}) \in \mathbb{R}^{d_p}, \quad a_i = E_{\text{pixel}}(x_t^{(i)}) \in \mathbb{R}^{d_a} $$

其中：
- $E_{\text{patch}}$：卷积或线性投影，对标标准 DiT 的 patch 嵌入。
- $E_{\text{pixel}}$：将原始 patch 映射到更高维的外观空间。

以 $P=32, C=3$ 为例，原始 patch 展开为 3072 维向量。$d_a$ 可设为等于或大于此值，从而保留近乎无损的外观信息。

### 2.3 子块分组（Subpatch Grouping）

像素分支的 $d_a$ 维 token **并非无结构的稠密向量**，而是被划分为 $n \times n$ 个 **子块组（Subpatch Groups）** ，每个子块对应 patch 内部的一个精细空间区域。

$$ a_i = [a_i^{(1)}, a_i^{(2)}, \ldots, a_i^{(n^2)}], \quad a_i^{(r)} \in \mathbb{R}^{d_a / n^2} $$

例如，当 $d_a = 3072, n = 8$ 时，每个 patch 被划分为 64 个子块组，每组 48 维。

**设计意图**：保留 patch 内部的空间组织结构，使模型具备显式的“内部几何”意识，而非将 patch 内所有像素混为一团。

### 2.4 层级位置编码（Hierarchical Positional Encoding）

为实现 patch 级与 subpatch 级空间信息的对齐，论文设计了 **双层 RoPE（Rotary Positional Encoding）** 方案：

- **Patch 级位置编码**：基于 patch 网格坐标 $(u, v)$，沿用标准 DiT 的 2D RoPE。
  $$ p_{\text{patch}}(u, v) = \text{RoPE}(u, v) $$

- **Subpatch 级位置编码**：在 patch 坐标基础上叠加子块相对偏移 $(\Delta_x(s), \Delta_y(t))$：
  $$ p_{\text{sub}}(u, v, s, t) = \text{RoPE}\big(u + \Delta_x(s),\; v + \Delta_y(t)\big) $$

其中 $(s, t)$ 为子块在 $n \times n$ 网格中的索引，偏移量归一化到 $[-0.5, 0.5]$ 区间。

### 2.5 交叉注意力机制（Cross-Attention）

这是两分支交互的核心模块（对应图 1 中的 **CrossDiTBlock**）：

1. **Query 来自像素分支**：每个子块组的 token $a_i^{(r)}$ 通过一个 **轻量级 MLP**（per-token，per-location，不同子块使用独立 MLP）投影为 query：
   $$ q_i^{(r)} = \text{MLP}_q(a_i^{(r)}) $$

2. **Key/Value 来自基分支**：基分支的 patch token $z_i'$（经 DiT block 处理后的输出）沿注意力头维度切分，再投影为 key 和 value：
   $$ k_i^{(h)} = W_k z_i'^{(h)},\quad v_i^{(h)} = W_v z_i'^{(h)} $$

3. **约束注意力范围**：每个子块 query **只与自己所属 patch 的 patch token 做交叉注意力**，不跨 patch 交互：
   $$ \alpha_i^{(r,h)} = \text{softmax}\left(\frac{\tilde{q}_i^{(r)} (\tilde{k}_i^{(h)})^\top}{\sqrt{d_h}}\right),\quad \hat{a}_i^{(r)} = \sum_{h} \alpha_i^{(r,h)} v_i^{(h)} $$

4. **更新像素分支**：每个子块组的输出经独立 MLP 投影后，以残差形式加回：
   $$ \hat{a}_i = a_i + \text{Concat}_r\left(\text{MLP}_r(\hat{a}_i^{(r)})\right) $$

**关键设计要点**：
- 信息流是 **单向的（Patch → Subpatch）**：基分支→像素分支，反之不然。
- 这种 **非对称设计** 避免了局部细节信息反向干扰全局结构的稳定性。

### 2.6 训练目标

采用 **$x_0$-prediction**（直接预测干净图像，而非噪声），由像素分支的最终输出经轻量级输出头投影得到预测 $\hat{x}_0$。

$$ \mathcal{L} = \mathbb{E}_{x_0, t, \epsilon} \left[ \| \hat{x}_0(x_t, t) - x_0 \|^2 \right] $$

## 6. 主要结论与发现

1. **双分支解耦有效**：将全局结构推理与局部外观建模分离，可有效突破像素空间 DiT 的表征瓶颈，且不依赖大幅增加模型参数。
2. **质量-效率 Pareto 提升**：在所有模型尺度（B/L/H/G）上，DuSPiT 均以 **更少或相当的 GFLOPs** 取得 **更低的 FID**：
   - Ours-G/32：FID **1.52**，GFLOPs **329**，优于 JiT-G/32 的 FID 1.78 / 384 GFLOPs。
3. **子块分组优于无结构扩维**：将额外维度组织为 $n \times n$ 子块网格，配以层级位置编码，是高效利用高维表征的关键。
4. **不对称交叉注意力最优**：仅让像素分支向基分支查询信息（Patch → Subpatch），双向交互或子块间自注意力反而损害性能，表明局部细节不应反向干扰全局结构。
5. **Per-token 投影优于共享投影**：不同子块需要独立的投影函数，共享参数会降低建模能力。

## 7. 优点（方法/实验亮点）

**方法创新**：
- 首次在像素空间扩散中提出 **全局与局部表征的显式分离**，视角新颖且有清晰的问题驱动。
- 子块分组设计既保留了 patch 内部空间结构，又控制了计算开销，是高维表征的高效利用方式。
- 层级位置编码统一了 patch 级和 subpatch 级的空间坐标，使交叉注意力具有明确的几何意义。

**实验设计**：
