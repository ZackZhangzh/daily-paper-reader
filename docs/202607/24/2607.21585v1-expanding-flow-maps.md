## 摘要
基于流的生成模型已在连续和离散状态空间上的快速可控生成方面取得了显著进展，但现有的参数化方法受限于固定维度或固定序列长度。本文引入扩展生成流（EFlows），其定义了沿扩展插值路径递增维度的分布之间的流，该路径通过条件噪声增广状态来实现维度的增长。在此构建基础上，我们提出扩展流映射（EFMs），这是一类新的流映射，能够将扩展插值路径蒸馏为高效的多步生成模型。每个EFM将任意两个时间步之间的映射分解为两个可学习的操作：扩展算子，其根据当前状态增广状态空间，添加新的坐标或标记；以及输运映射，其将扩展后的状态沿插值路径向前推进。复合这些算子得到一个单一映射，该映射联合扩展状态并去噪，当扩展算子为恒等映射时，可恢复现有的固定画布流和流映射作为特例。我们进一步将该框架推广至离散单纯形，从而支持变尺寸图生成和变长序列生成。在连续和离散模态上，我们将EFlows和EFMs确立为输出尺寸本身是一个可学习的可控自由度情形下的原则性框架。

## Abstract
Flow-based generative models have enabled remarkable progress in fast and controllable generation across continuous and discrete state spaces, yet existing parameterizations are constrained to fixed dimensions or fixed sequence lengths. Here, we introduce Expanding Generative Flows (EFlows), which define flows between distributions of increasing dimensionality along an expanding interpolant that grows the state by augmenting it with conditional noise. Building on this construction, we propose Expanding Flow Maps (EFMs), a new class of flow maps that distill the expanding interpolant into efficient few-step generative models. Each EFM factors the map between any two timesteps into two learnable operations: an expand operator, which augments the state space with new coordinates or tokens conditioned on the current state, and a transport map, which pushes the expanded state forward along the interpolant. Composing these operators yields a single map that jointly expands and denoises the state, recovering existing fixed-canvas flows and flow maps as the special case in which the expand operator is the identity. We further extend the framework to the discrete simplex, enabling variable-size graph generation and variable-length sequence generation. Across both continuous and discrete modalities, we establish EFlows and EFMs as a principled framework for settings in which output size is itself a learned, controllable degree of freedom.

## 一、核心问题与整体含义

**研究动机**：现有流映射（Flow Maps）生成模型虽已支持连续与离散状态空间上的少步生成，但根本上受限于**固定画布**——即固定的连续空间维度 d 或固定的离散序列长度 L。然而，许多真实世界的生成任务（变分辨率图像、任意时长音视频、未知长度的语言序列、多模态数据等）要求输出尺寸本身成为一个可建模的量。核心问题在于：**如何在推理阶段实现连续与离散数据的自适应维度少步生成**。

**整体含义**：本文提出**扩展流映射（Expanding Flow Maps, EFMs）** 框架，将流映射分解为**扩展算子**（根据当前状态增广新坐标/标记）与**输运映射**（沿插值路径推进扩展后的状态）两个可学习操作的复合，从而让状态空间能够在推理过程中动态增长。该框架统一了连续与离散模态的变维度生成，并将固定维度流映射恢复为其特例（扩展算子为恒等映射时）。

## 二、方法论

### 2.1 扩展生成流（EFlows）

**核心思想**：用非递减维度调度 d(t): [0,1] → ℕ 替代固定维度 d，使边际分布 pt ∈ P(ℝ^(d(t))) 定义在时变状态空间上。由于 s < t 时 d(s) < d(t)，源状态与目标状态处于不同维度空间，不存在微分同胚，因此通过**条件噪声增广**将源状态提升至目标维度，再施加输运。

**关键技术**：

- **扩展算子 E_s,t**：ℝ^(d(s)) × ℝ^(d(t)-d(s)) → ℝ^(d(t))，将源状态与增广噪声 ϵ 按指定方案（拼接、位置插入、子节点扩展）组合。
- **局部时间坐标**：每个新插入的坐标拥有独立的局部时间 t_i = (t - t_ins^i)/(1 - t_ins^i)，使所有维度在共同的局部时钟上被去噪。
- **PDMP 表征**：将扩展流形式化为**分段确定性马尔可夫过程（PDMP）**，其扩展生成器由输运项和跳跃核两项组成，统一了平滑去噪与维度跳跃。

### 2.2 扩展流映射（EFMs）

**核心思想**：将扩展插值路径蒸馏为少步生成模型。

**连续空间 EFM**：
Φ_s,t = X_s,t ∘ E_s,t，Φ_s,t(x_s) := X_s,t(E_s,t(x_s)) = E_s,t(x_s) + (t - s)v_s,t(E_s,t(x_s))

**离散空间 EFM**（基于单纯形 ∆^(V-1)）：
用**均值去噪器 ψ_s,t** 替代速度场，Φ_s,t(x_s) = (1-t)/(1-s) · E_s,t(x_s) + (t-s)/(1-s) · ψ_s,t(E_s,t(x_s))

**训练目标**：对角线损失（L_diag）+ 一致性损失（L_cons），一致性条件包括拉格朗日、欧拉和半群条件，在离散情形下以交叉熵形式实现。

### 2.3 离散序列与图的扩展

- **序列**：每个 token 拥有独立插入时间，插入头预测每间隙的期望插入数，扩展算子按二项分布采样插入数量。
- **图**：节点与边协同扩展，边继承两端节点的局部时间，边缘矩阵保持对称且对角为零。

## 六、主要结论与发现

1. **EFlow（多步）**：在分子构象生成中，以 16-50 倍少于扩散基线的步数取得竞争力甚至更优的性能；在 GEOM-Drugs 上包揽全部四项指标最佳或次佳。
2. **EFM（少步）**：蒸馏后的 EFM 在 4 步、2 步乃至 1 步生成中表现强劲，EFM+R 在 GEOM-Drugs 全部四项指标上取得最佳。
3. **离散分子图**：EFlow 在 10 步时 FCD 仅轻微退化（0.390），而 DeFoG 跌至 1.630；EFM 在 1 步时 FCD 为 0.44，比 CFM（2.14）低近 5 倍。
4. **语言建模**：EFlow 在所有步数下困惑度均优于固定长度 FLM；EFM 在 2 步和 4 步时生成连贯文本，优于所有蒸馏扩散基线。
5. **统一性**：EFlows 和 EFMs 成为首个同时支持连续与离散、多步与少步、固定与可变维度的统一生成框架。
