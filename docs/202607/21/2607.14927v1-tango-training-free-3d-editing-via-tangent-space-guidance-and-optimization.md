## 摘要
尽管近年来基于流匹配的3D生成模型（如VecSet）采用了结构化表示，但其token共享全局上下文，导致传统的免训练编辑会出现语义伪影，例如保留区域坍塌或变换不完整。为解决这一问题，我们提出TanGO，一个免训练框架，能够在生成动态的切空间中对每个token进行自适应调控。为实现这种选择性控制，我们制定了一个单步最优控制规则，并利用源自源速度场和目标速度场的、受von Mises-Fisher启发的方向差异度量，来确定每个token控制信号的强度。实验表明，TanGO显著减少了结构伪影，达到了最先进的性能，优于现有的3D编辑基线。代码已公开于https://github.com/siw00-lim/TanGO。

## Abstract
While recent flow-matching 3D generative models (e.g., VecSet) adopt structured representations, their tokens share global context, causing conventional training-free editing to suffer from semantic artifacts such as collapsed preserved regions or incomplete transformations. To address this, we propose TanGO, a training-free framework that enables adaptive per-token steering in the tangent space of generative dynamics. To realize this selective control, we formulate a one-step optimal control rule and determine the strength of each token's control signal using a von Mises-Fisher inspired directional discrepancy derived from the source and target velocity fields. Experiments show that TanGO substantially reduces structural artifacts and achieves state-of-the-art performance, outperforming existing 3D editing baselines. The code is publicly available at https://github.com/siw00-lim/TanGO.

## 二、方法论

**核心思想：**

将3D编辑形式化为切空间中的逐token控制分配问题。核心在于解耦两个问题：（1）在哪些token上施加控制（局域化）；（2）施加多大的控制强度（轨迹级引导）。

**关键技术细节：**

1. **单步最优控制律**：在每个ODE步骤中，通过最大化朝向目标切线方向的一阶进度，并惩罚过度的控制能量，得到闭式解：

   $$u_i^*(t) = \frac{d_i(t)}{\rho} \Delta v_i(t)$$

   其中$d_i(t)$是逐token的需求强度，$\Delta v_i(t)$是源速度场与目标速度场之差。

2. **基于von Mises-Fisher（vMF）的方向差异度量**：将源速度方向和目标速度方向建模为单位超球面上的vMF分布，定义需求$d_i(t) = 1 - \cos\theta_i(t)$。对齐方向获得接近零的需求，而较大偏差意味着更强的驱动。

3. **均值增益归一化**：为稳定整体引导能量，引入$\lambda_{\text{eff}}(t) = \lambda \cdot \eta / (\bar{g}(t) + \varepsilon)$，补偿均值增益$\bar{g}(t)$沿积分轨迹的波动。

4. **纹理烘焙流水线**：通过多视图扩散模型和修复模型生成并烘焙纹理图，弥补VecSet模型原生纹理管线的缺失。

6. **方法具有跨模型泛化性**：在TripoSG上同样能成功执行语义编辑。


## 七、方法亮点

1. **免训练（Training-Free）** ：无需对生成模型进行微调或重训练，即可实现高质量编辑。

2. **无需掩码（Mask-Free）** ：通过速度场方向差异自动识别需要编辑的区域，无需人工标注编辑掩码。

3. **切空间最优控制框架**：将编辑形式化为有闭式解的最优控制问题，理论清晰、计算高效。

4. **vMF引导的逐token自适应**：基于方向差异而非幅度差异，对速度大小变化具有鲁棒性。

5. **最小干预原则**：限制更新方向仅沿源流向目标流的转移方向，避免正交扰动损害保留区域。

6. **纹理烘焙流水线**：解决了VecSet模型缺乏原生纹理管线的问题，使编辑结果可直接用于下游应用。

7. **开源与可复现**：代码已公开，并提供了TanGOEdit基准（100个精选样本）。
