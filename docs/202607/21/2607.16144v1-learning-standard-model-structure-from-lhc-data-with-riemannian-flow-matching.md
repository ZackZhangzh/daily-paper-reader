## 摘要
在这项工作中，我们证明了一个基于Transformer的单一生成模型能够捕获跨越五个数量级不变质量的标准模型结构，从亚GeV能区到TeV连续区，这一范围是任何单一蒙特卡罗样本都无法覆盖的。为实现这一目标，我们设计了\textsc{ShellFlow}，一种黎曼条件流匹配模型，该模型在给定记录的事例组成后，为每个粒子在其壳流形上生成样本。其仅有的物理先验是壳条件和不变质量公式。该模型在ATLAS开放数据13~TeV发布版中约$10^{9}$个真实$pp$对撞事例上训练，且未被告知任何其他信息。通过单次训练运行，该模型学会重现以下全部内容：粒子内部运动学、位于PDG位置的双轻子共振峰（$J/ψ$、$Υ$、$Z$）、轻子韦恩伯格角、$W$和顶夸克质量，以及未进入训练目标中的粒子间关联。因此，标准模型的相当大一部分可以直接从记录的对撞数据中学习得到。

## Abstract
In this work we demonstrate that a single transformer-based generative model can capture Standard Model structure spanning five decades of invariant mass, from the sub-GeV regime to the TeV continuum, a range that no single Monte Carlo sample covers. To achieve this we design \textsc{ShellFlow}, a Riemannian conditional flow matching model that, given the recorded event composition, generates each particle on its on-shell manifold. Its only physics priors are the on-shell condition and the invariant-mass formula. The model is trained on $\sim 10^{9}$ real $pp$ collision events from the ATLAS Open Data 13~TeV release and told nothing else. From a single training run, the model learns to reproduce all of the following: intra-particle kinematics, the dilepton resonances ($J/ψ$, $Υ$, $Z$) at their PDG positions, the leptonic Weinberg angle, the $W$ and top-quark masses, and inter-particle correlations that enter no training objective. A substantial fraction of the Standard Model is thus learnable directly from recorded collision data.

## 一、核心问题与整体含义（研究动机和背景）

**核心问题**：LHC产生的对撞数据量极其庞大，但当前的数据解释完全依赖蒙特卡罗（MC）事件生成器（如Pythia、Herwig、Sherpa等），这些生成器需要针对每个特定物理通道或新物理信号假说分别调参。探测器级MC模拟计算成本高昂，且每次分析只针对单一通道，难以评估众多新物理场景中哪些真正与数据兼容。

**核心挑战**：现有MC样本无法单一覆盖从亚GeV到TeV跨越五个数量级的不变质量范围。

**本文贡献**：首次证明一个基于Transformer的单一生成模型，在仅以壳条件和不变质量公式为物理先验的情况下，可以直接从约10⁹个ATLAS真实对撞事件中学习到标准模型的大量结构。模型不依赖任何MC模拟，也不需要任何通道标签或特定任务的训练目标。


## 二、方法论（核心思想、关键技术细节）

**核心思想**：设计 **ShellFlow**——一种基于**黎曼条件流匹配（Riemannian Conditional Flow Matching）** 的生成模型。将每个粒子生成在其**壳流形（on-shell manifold）** 上，使壳条件 `E² = m² + |p|²` 在生成时自动成立。

**关键技术细节**：

1. **粒子流形分解**：
   - 无质量粒子（电子、缪子、光子）：流形为 `R × S²`，参数为对数能量 `yE` 和三维动量方向 `ˆn`
   - 有质量粒子（强子衰变τ、小R喷注、大R喷注）：流形为 `R × S² × R`，额外生成重构质量 `zm`
   - 单位球面 `S²` 上的测地线使用球面线性插值（slerp），确保方向生成在流形上

2. **双头（Dual-Head）Transformer架构**：
   - **主头**：预测流匹配速度场 `vθ`，优化RCFM损失
   - **辅助头**：预测K体不变质量的速度，携带`K`体质量监督信号（`K=2,3,4`），且不参与生成积分器

3. **两项关键损失**：
   - **主损失（RCFM）**：用Huber损失替代二次范数，并用粒子质量分数 `qeff` 调制，使高质量重构粒子对梯度贡献更大
   - **辅助损失（K体质量）**：监督每个粒子元组的对数不变质量及其时间导数。引入**分布匹配权重 `w⋆`**，在模型欠产的质量区域放大梯度信号，在过产区域抑制梯度

4. **条件输入**：粒子类型、电荷、探测器额外特征作为条件信号（cond）；缺失横能量（MET）通过交叉注意力注入。


## 三、实验设计（数据集、基准、对比方法）

**数据集**：
- ATLAS Open Data 13 TeV pp碰撞数据发布版中的 **2-to-4 lepton** 和 **1LMET30** 两个skim的并集
- 去重后约 **7.8×10⁸ 训练事件**，**4.1×10⁷ 验证事件**（95/5分割）
- 限制每个事件重构粒子数 `N_particles ≤ 8`

**评估方式**：
- 三个标量一致性指标：**1-Wasserstein距离（W1）**、**对称KL散度（SKL）**、**Bray-Curtis不相似度（BC）**
- 所有生成样本与验证集（held-out truth）对比，使用相同的ATLAS风格分析选择

**对比方法（消融实验）**：训练四个变体：
1. ShellFlow（完整配置：壳流形 + K体辅助损失）
2. 欧几里得 + 辅助损失（无壳流形）
3. 壳流形 + 无辅助损失
4. 欧几里得 + 无辅助损失（纯基线）

所有变体训练2个epoch，超参数保持一致。

## 六、主要结论与发现

1. **共振峰精确复现**：J/ψ(1S)、ψ(2S)、Υ家族、Z峰均出现在PDG公布位置，覆盖五个数量级的不变质量范围

3. **重粒子质量**：强子顶、轻子顶、强子W、轻子Z的重构质量峰与truth闭合

4. **未监督的粒子间关联**：`∆Rℓℓ`、`∆ϕ(ℓℓ, MET)`、`mT`、`HT`、领头和次领头轻子`pT`等未进入任何训练目标的观测量，均被模型精确复现

5. **横向动量守恒**：事件级`pT`闭合复现了联合样本的双分量结构

6. **双喷注运动学**：`(mjj, ¯η)`联合分布复现了部分子动量分数 `x₁, x₂ ≤ 1` 的三角包络


## 七、优点（方法或实验设计的亮点）

1. **首个完全数据驱动的广域生成模型**：不依赖任何MC模拟，仅从真实对撞数据学习，开创了从数据直接学习标准模型结构的新范式

2. **物理先验极简而精准**：仅两个洛伦兹不变先验（壳条件 + 不变质量公式），不对任何特定通道或共振引入偏置

3. **黎曼流形的巧妙设计**：将粒子生成约束在物理壳流形上，从根本上消除了四动量独立波动造成的质量展宽

4. **双头架构 + 分布匹配权重**：主头负责流匹配，辅助头专门监督K体质量，二者解耦避免共振锐化损害连续区建模；`w⋆` 使模型能在噪声淹没共振的情况下仍恢复窄峰

5. **评估的全面性与严谨性**：三大一致性指标（W1、SKL、BC）+ 标准ATLAS分析选择 + 再生种子稳定性检验

6. **消融实验设计清晰**：4组变体系统证明了壳流形和辅助损失各自的关键作用


## 八、不足与局限

**物理层面的未解决问题**：

1. **亚GeV矢量介子缺失**：ω(782)和ϕ(1020)在生成谱中完全消失——CFM前向加噪在极早期就将它们淹没，即便`w⋆`重加权也无法在当前分辨率下恢复

2. **Higgs黄金通道失败**：在完整的 `H → ZZ* → 4ℓ` 质量选择后，生成谱退化为无特征连续区，无法复现Z→4ℓ峰（91 GeV）和Higgs峰（125 GeV）

3. **强子侧共振核稀释**：强子顶和强子W的共振核心比truth浅且宽（核心内产额分别低9%和23%），自由形状拟合无法收敛

4. **η≈0处的浅层缺陷**：在所有粒子类型中普遍存在，来源未确定

**系统性限制**：

5. **粒子类型和电荷为条件输入而非生成**：模型不推断粒子身份，仅生成给定身份下的运动学

6. **MET为条件输入而非生成**：生成事例不自洽包含MET，无法用于涉及中微子的自洽分析

7. **固定粒子多重性**：训练限制 `N_particles ≤ 8`，丢弃了高多重性尾部

8. **物理 vs. 统计的未决问题**：模型是真正“学会”了物理还是仅复现了训练数据中的统计关联，需要通过 mechanistic interpretability 回答
