## 摘要
文本到图像（T2I）生成的最新进展使得通过引入文本以外的条件来实现可控图像合成成为可能。然而，现有大多数基于扩散的方法仅限于单一类型的控制条件（例如边界框或关键点），这限制了它们的灵活性。为应对这一局限，我们提出了MixDiffusion，一种无需训练的多条件T2I生成扩散框架。MixDiffusion理论上支持任意数量的控制条件，包括边界框、关键点、草图、深度图、参考图像和文本，通过协同整合多个预训练的单条件扩散模型来实现。该方法的核心洞察在于，利用推导出的积分公式，从多个基于扩散的单条件模型的预测噪声分布中导出多条件图像生成模型在每一步去噪过程中的预测噪声分布，该公式有严格的理论证明。由于其免训练的特性，MixDiffusion易于部署，并且可以方便地扩展到新的控制模态。

## Abstract
Recent advances in text-to-image (T2I) generation have enabled controllable image synthesis by incorporating conditions beyond text. However, most existing diffusion-based methods are limited to a single type of control condition (e.g., bounding boxes or keypoints), which restricts their flexibility. To address this limitation, we propose MixDiffusion, a training-free diffusion framework for multi-condition T2I generation. MixDiffusion theoretically supports an arbitrary number of control conditions, including bounding boxes, keypoints, sketches, depth maps, reference images, and text, by collaboratively integrating multiple pre-trained uni-condition diffusion models. The key insight of the proposed approach is to derive the predicted noise distribution in each denoising step of the diffusion-based multi-condition image generation model from the predicted noise distributions of multiple diffusion-based uni-condition models with a derived integration formula, which is supported by rigorous theory proof. Owing to its training-free nature, MixDiffusion is easy to deploy and readily extensible to new control modalities.

## 一、核心问题与整体含义

**研究背景**：文本到图像生成模型（如 Stable Diffusion、Imagen、DALL-E 等）已能生成高质量图像，但在可控细节生成方面存在明显不足，例如在图像中精确放置物体、渲染特定姿态的人物等。

**核心问题**：现有可控图像生成方法大多仅支持单一类型的控制条件（如边界框或关键点），限制了其灵活性。少数多条件模型（如 Uni-ControlNet、Diffblender）也只支持固定且有限的控制条件组合，新增控制模态需要重新训练模型，耗时且昂贵。

**研究目标**：本文提出 **MixDiffusion**，一个无需训练的多条件 T2I 生成扩散框架，理论上支持**任意数量**的控制条件（包括边界框、关键点、草图、深度图、参考图像和文本），通过协同整合多个预训练的单条件扩散模型来实现多条件联合生成。

## 二、方法论

**核心思想**：在扩散模型的每一步去噪过程中，利用推导出的积分公式，从多个单条件扩散模型的预测噪声分布中导出多条件模型的预测噪声分布。

**关键技术细节**：

1. **框架结构**：MixDiffusion 遵循标准扩散模型的去噪策略。每一步中，各控制条件由对应的 Condition Processor 提取特征，输入预训练的单条件去噪器预测噪声，最后通过 Integration Module 整合得到最终预测噪声并去除。

2. **共享组件**：多个单条件模型共享相同的 VAE 和文本编码器以节省显存和计算开销。

3. **积分公式推导**：基于贝叶斯规则，在条件独立性假设下，推导出“专家乘积”风格的融合公式：
   - 对于 DDIM 调度器（各模型方差相同）：**ε_joint = Σ ε_i − (N−1)·ε_base**
   - 其中 ε_i 为各单条件模型预测噪声，ε_base 为无条件基模型预测噪声。

4. **积分强度策略**：早期去噪步骤决定物体的轮廓和位置，后期步骤侧重细节刻画。因此采用**动态递减**的积分强度：w = (t/T)²，让基模型在后期承担主要去噪任务以提升细节质量。

5. **泛化到 Flow Matching**：将噪声预测替换为速度预测，推导出考虑各专家方差的加权融合公式。

## 六、主要结论与发现

1. MixDiffusion 在控制精度上**优于**所有对比的多条件生成模型，能更好地遵循控制条件生成图像。
2. 提出的积分公式**优于**简单的插值策略，尤其在整合较多模型时优势更明显。
3. 积分强度调整策略能有效提升图像质量和对齐程度。
4. **随着控制条件数量增加**，OKS、IoU、美学评分和 ImageReward 均持续提升——更多条件相互补充验证，使输出更符合预期。
5. MixDiffusion 提供了一种**灵活、可扩展、无需训练**的多条件生成解决方案，便于实际部署。

## 七、方法亮点

1. **免训练**：无需重新训练或微调，直接利用现有预训练模型，大幅降低部署成本。
2. **理论完备**：从贝叶斯规则和扩散模型理论出发，严格推导了积分公式，具有可解释性。
3. **灵活可扩展**：理论上支持任意数量、任意类型的控制条件，新增控制模态只需接入对应的预训练单条件模型。
4. **共享组件优化**：通过共享 VAE 和文本编码器，有效控制了计算开销。
5. **泛化能力强**：方法可推广到 Flow Matching 等不同的扩散框架。

## 八、不足与局限

1. **实验覆盖有限**：仅在 COCO 2017 上验证，未在更多样化的数据集（如 LAION、ADE20K 等）上测试泛化能力。
2. **条件类型局限**：实际验证的条件类型为六种，虽然理论上支持任意数量，但更多条件组合的实际效果尚未充分验证。
3. **计算开销**：生成时间为 SD1.5 的 1.5 倍，且随条件数量增加可能线性增长（尽管可并行运行）。
4. **依赖预训练模型质量**：最终生成质量受限于所集成的单条件模型本身的能力。
5. **条件独立性假设**：推导中假设了条件独立性（P(C₁,…,C_N | ε, z_t) = Π P(C_i | ε, z_t)），实际中不同控制条件可能存在相关性，该假设的合理性有待进一步讨论。
6. **偏差风险**：未讨论不同条件冲突时的处理机制（如边界框与姿态矛盾时如何权衡）。
