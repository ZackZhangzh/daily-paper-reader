## 摘要
在推理任务上训练的语言模型 $p_θ(y \mid x)$ 会通过多种不同策略学习解决问题，然而这些策略是隐式的，且纠缠在模型的响应分布中。我们研究将给定预训练语言模型的响应分布分解为结构化的、以策略为条件的表示的问题。具体而言，我们学习一个隐变量分解 $p_θ(y \mid x) \leadsto (r_φ(z \mid x), g_φ(y \mid x,z))$，其中路由器 $r$ 将每个输入映射到潜在策略 $z$ 上的分布，生成器 $g$ 则在该策略条件下生成响应。一个关键挑战在于，从基础模型初始化的生成器在不使用 $z$ 的情况下已经能够表示 $p_θ(y \mid x)$。因此，标准变分推断不会促使模型通过 $z$ 传递信息，并可能导致严重的后验坍塌。为应对这一问题，我们提出一个变分目标，该目标测量相对于基础模型响应损失的分段信息增益，并将重构压力集中在基础模型高困惑度的词元上，从而鼓励 $z$ 编码与策略相关的响应变化。我们引入了一个多策略算法任务基准，并表明该目标能够恢复与不同参考策略对齐的潜在编码，同时保持基础模型的响应分布。

## Abstract
A language model $p_θ(y \mid x)$ trained on reasoning tasks learns to solve problems via multiple distinct strategies, yet these strategies are implicit and entangled within the model's response distribution. We study the problem of decomposing the response distribution of a given pretrained language model into a structured, strategy-conditioned representation. Specifically, we learn a latent-variable factorization $p_θ(y \mid x) \leadsto (r_φ(z \mid x), g_φ(y \mid x,z))$, where a router $r$ maps each input to a distribution over latent strategies $z$ and a generator $g$ produces the response conditioned on that strategy. A key challenge is that the generator, initialized from the base model, already represents $p_θ(y \mid x)$ without using $z$. Standard variational inference therefore gives the model no incentive to route information through $z$ and can yield a severe form of posterior collapse. To address this, we propose a variational objective that measures fractional information gain relative to the base model's response loss and concentrates reconstruction pressure on tokens with high base model surprisal, encouraging $z$ to encode strategy-relevant response variation. We introduce a benchmark of multi-strategy algorithmic tasks and show that this objective recovers latent codes aligned with distinct reference strategies while preserving the base model's response distribution.

## 2. 方法论

**核心思想：**

提出一个**模型导向的重构目标（Model-Directed Reconstruction）**，用基础模型 $p_\theta$ 本身作为参照，将重构压力集中在基础模型**高困惑度（高 surprisal）**的词元上，鼓励 $z$ 编码与策略相关的响应变化。

**关键技术细节：**

1. **架构**：将预训练 Transformer 改造为三个角色——路由器 $r_\phi(z \mid x)$（从输入产生隐变量分布）、策略条件生成器 $g_\phi(y \mid x, z)$（在隐变量条件下自回归生成响应）、以及训练时后验 $q_\xi(z \mid x, y)$（从完整输入-响应对推断隐变量）。路由器添加高斯投影头，隐变量采样后投影为嵌入伪词元插入序列。两个模型均从基础参数 $\theta$ 初始化，使用 LoRA 式低秩适配。

2. **标准 ELBO 的失败**：条件 ELBO 目标为：
   $$J_{\text{cELBO}}(x,y;\phi,\xi)=\mathbb{E}_{z\sim q_\xi(\cdot|x,y)}[-\log g_\phi(y|x,z)]+\text{KL}(q_\xi(\cdot|x,y)\|r_\phi(\cdot|x))$$
   该目标仅要求诱导边际 $p_\phi(y \mid x)$ 匹配观测响应分布，不要求 $z$ 解释 $y$ 中超越 $x$ 的变化。

3. **模型导向重构目标**：
   $$J_\theta(x,y;\phi,\xi)=R_\theta(x,y;\phi,\xi)+\beta\,\text{KL}(q_\xi(\cdot|x,y)\|r_\phi(\cdot|x))$$
   其中重构项 $R_\theta$ 定义为：
   $$R_\theta(x,y;\phi,\xi)=\frac{1}{c_\theta}\mathbb{E}_{z\sim q_\xi(\cdot|x,y)}\left[\sum_{t=1}^{T_y} a_{\theta,t}(x,y)\big[-\log g_\phi(y_t|x,z,y_{<t})\big]\right]$$
   - $b_{\theta,t}(x,y)=-\log p_\theta(y_t|x,y_{<t})$ 为基础模型词元困惑度
   - $c_\theta=\mathbb{E}[b_\theta(x,y)]$ 为全局参考尺度
   - $a_{\theta,t}$ 为均匀权重与 surprisal 导向权重的凸组合，参数 $\alpha \in [0,1]$ 控制混合比例

**算法流程：**
1. 从基础模型采样 $(x,y) \sim p_\theta(\cdot \mid x)$
2. 计算冻结基础模型的词元困惑度 $b_{\theta,t}$ 和权重 $a_{\theta,t}$
3. 从后验 $q_\xi(\cdot \mid x,y)$ 采样或重参数化 $z$
4. 计算目标函数 $J_\theta$，更新 $\phi$ 和 $\xi$，保持 $\theta$ 固定
